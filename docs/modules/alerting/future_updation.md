# Alerting Module Future Updates & Roadmap

This document describes upcoming features, multi-window anomaly detection, and synthetic monitoring for the **Alerting Module**.

---

## 1. Planned Enhancements

1. **Multi-Window Multi-Burn-Rate Alerts (Google SRE Style)**: Evaluate both 1-hour (rapid burn) and 6-hour (slow burn) error budget consumption windows.
2. **Synthetic API & Web Checks**: Periodic external uptime and HTTP payload validation checks running from global edge probes.
3. **On-Call Schedule Rotations**: Built-in on-call schedule calendar with automatic escalation phone/SMS routing.
