# Observability Module Future Updates & Roadmap

This document outlines future capabilities and architectural evolutions for the **Observability Module**.

---

## 1. Planned Innovations

1. **Automated Critical Path Analysis**: Graph algorithms to automatically compute and highlight the exact bottleneck span on the latency critical path.
2. **OpenTelemetry Exemplar Support**: Deep correlation between Prometheus histogram buckets and exact trace exemplars.
3. **eBPF Kernel-Level Tracing**: Ingestion of kernel network and file I/O latency traces from eBPF host agents.
4. **AI-Powered Flamegraphs**: Dynamic aggregation of distributed CPU profiling flamegraphs correlated with high-latency traces.
