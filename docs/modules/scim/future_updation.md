# SCIM 2.0 Module Future Updates & Roadmap

This document describes upcoming features and enterprise directory integrations for the **SCIM Module**.

---

## 1. Planned Roadmap

1. **JIT (Just-In-Time) SAML + SCIM Reconciliation**: Automated resolution of attribute conflicts between SAML claims and SCIM directory updates.
2. **Custom Enterprise Schema Extensions**: Support for `urn:ietf:params:scim:schemas:extension:enterprise:2.0:User` (department, costCenter, manager).
3. **Automated Okta / Entra SCIM Test Suite**: Continuous automated validation against official IdP SCIM conformance test suites.
