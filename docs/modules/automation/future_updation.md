# Automation Module Future Updates & Roadmap

This document outlines upcoming workflow visualizers, step-function orchestrations, and cloud provider remediations for the **Automation Module**.

---

## 1. Planned Roadmap

1. **Visual Drag-and-Drop Workflow Builder**: Low-code DAG (Directed Acyclic Graph) workflow builder with branching, loops, and approval gates.
2. **Native Cloud Provider Remediations**: Pre-built integration actions with AWS (Lambda invoke, ECS restart), GCP (Cloud Run revision rollback), and Kubernetes (pod restart).
3. **AI Playbook Recommendations**: Suggest automated playbook rules based on recurring operational incident patterns.
