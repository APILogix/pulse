# Webhooks Module Future Updates & Roadmap

This document describes upcoming webhook portal features and scaling enhancements for the **Webhooks Module**.

---

## 1. Planned Enhancements

1. **Embedded Customer Webhook Portal**: Provide customers with an embedded Svix-style UI to test, debug, and inspect their own webhook endpoints.
2. **Mutual TLS (mTLS) Authentication**: Support enterprise client certificates for high-security webhook delivery.
3. **Automated Endpoint Circuit Breakers**: Auto-pause webhook deliveries to consistently failing endpoints and notify account owners.
