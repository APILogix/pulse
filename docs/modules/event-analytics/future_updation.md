# Event Analytics Module Future Updates & Roadmap

This document outlines future enhancements and scaling optimizations for the **Event Analytics Module**.

---

## 1. Planned Capabilities

1. **Self-Service Funnel Builder**: UI-driven visual query builder supporting arbitrary property breakdown dimensions (e.g. browser, country, plan).
2. **Real-time Streaming Funnels**: In-memory windowed state aggregations for instant conversion tracking without database table scans.
3. **Automated User Path Discovery**: Graph discovery algorithms mapping top branching user navigation paths across applications.
