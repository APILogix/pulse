# User Account Module Future Updates & Roadmap

This document describes upcoming account security features and developer tooling integrations for the **User Account Module**.

---

## 1. Planned Enhancements

1. **Granular OAuth Application Authorizations**: Allow third-party apps to request scoped permissions on behalf of the user.
2. **Account Deletion & Automated Right-to-be-Forgotten Engine**: Automated cascaded redaction of PII across all active and archived databases.
3. **Session Anomaly Alerts**: Instant transactional email and push alerts when a login occurs from an unrecognised device or ASN.
