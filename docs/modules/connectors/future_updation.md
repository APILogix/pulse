# Connectors Module Future Updates & Roadmap

This document describes upcoming integrations and two-way interaction features for the **Connectors Module**.

---

## 1. Planned Enhancements

1. **Two-Way Slack Bot Actions**: Acknowledge, resolve, and silence alerts directly from interactive Slack action buttons and modal dropdowns.
2. **Additional Enterprise Connectors**: Pre-built native integrations for ServiceNow, Jira Service Management, Opsgenie v2, and VictorOps.
3. **Delivery Observability & Redelivery UI**: Visual timeline of all dispatched notifications with HTTP request/response inspection and manual redelivery triggers.
